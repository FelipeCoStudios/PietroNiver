# Crazy Cartoon Football

Jogo de futebol arcade/cartoon caótico em HTML5 puro.

## Como jogar

1. Descompacte o ZIP
2. Abra `index.html` no navegador (Chrome, Edge, Firefox, Safari)

## Controles

**Jogador 1**
- WASD — mover
- ESPAÇO — chutar
- SHIFT — item
- E — ação

**Jogador 2**
- Setas — mover
- ENTER — chutar
- CTRL direito — item
- BACKSPACE — ação

ESC — pausa

## Modos

- **Jogar Sozinho** — vs IA (9 níveis)
- **Cooperativo** — 2 jogadores local
- **Treino** — prática livre

## Itens

Bomba, Raio-X, Pão, Tênis, Vórtex, Ímã, Raio, Gelo, Bumerangue, Balão

## Adicionar sons

Coloque arquivos em `assets/sounds/` (kick.mp3, goal.mp3 etc.).  
O jogo gera sons via Web Audio se não houver arquivos.

## Publicar

**GitHub Pages:** push do repositório e ative Pages na pasta raiz.  
**Netlify:** arraste a pasta do projeto.
